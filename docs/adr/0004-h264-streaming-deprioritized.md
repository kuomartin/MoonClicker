# H264 streaming pipeline deprioritized

The H264EncoderSink + LocalSocket streaming pipeline (virtual display → encoded video → VideoPlayerUI/FrameGrabber) was left mid-integration and is now explicitly shelved — it turned out not to matter for the project's current goals. Don't pick it back up or block other work on it without a fresh decision.

## Status

Accepted. Deprioritized as of 2026-09-09; not resumed.
