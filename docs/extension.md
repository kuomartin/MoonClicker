# 使用 VS Code 腳本工作台遠端開發

## 安裝擴充套件

1. 從 [Releases](https://github.com/kuomartin/MoonClicker/releases) 下載最新的 `moonclicker-script-workbench.vsix`。
2. 在 VS Code 執行 **Extensions: Install from VSIX...** 指令，選擇下載的檔案完成安裝。

## 連線裝置

1. 在 App 的 `設定` → `關於` 連按版本號 7 下開啟開發人員選項，再到 `開發人員選項` 開啟 `腳本工作台`，並開啟配對模式。
2. 點擊側邊欄 **MoonClicker Scripts** -> **Connect to Device**：VS Code 會透過 mDNS 自動搜尋同網段內的裝置，選取即可配對；找不到裝置時也可以手動輸入裝置 IP 與 PIN 碼。

## 腳本資料夾

第一次連上一台裝置時，VS Code 會請你選一個本機資料夾，裝置上的每支腳本是其中一個子資料夾。選好後會在目前視窗開啟它；之後再連同一台裝置會直接沿用。換了資料夾或清除 App 資料後，會重新詢問。

每次連線都會先比對兩邊：只有一邊改過的檔案同步到另一邊；一邊刪除、另一邊沒動的檔案兩邊都刪掉；一邊刪除、另一邊有修改的檔案保留修改的版本。兩邊都改過而且內容不同時，保留本機版本，裝置上的版本另存成同一個位置的 `<檔名>.device`，下次存檔就會以本機版本覆蓋裝置。整支腳本的資料夾在本機被刪掉時，會先詢問是否也刪除裝置上的腳本。

連線期間，本機的新增、修改、刪除會即時推上裝置，裝置上透過腳本工作台的改動也會即時拉回來。直接在手機上用 App 或檔案管理員做的改動，要等下次連線才會同步。

本機新增的子資料夾要有 `main.lua`，而且名稱只能是小寫英數字、`.`、`_`、`-`，才會在裝置上建立成新腳本；也可以用側邊欄標題列的 **New Script** 建立。資料夾根目錄的 `.moonclicker/` 記錄同步狀態，`.luarc.json` 提供 Lua API 型別提示，兩者都不會同步到裝置。

## 連線後可以做什麼

* **F5 執行、Shift+F5 停止**：在 `main.lua` 編輯器內按 F5 於裝置上執行目前的腳本並即時查看日誌，Shift+F5 停止。
* **Workbench 面板**：點狀態列的連線狀態或側邊欄標題列的按鈕開啟。包含低延遲 H.264 即時畫面、框選模板、測試模板與 OCR；預設開啟上次看的顯示器，可在面板內切換，實體螢幕尚未啟動鏡像時面板內會顯示啟動按鈕。
* **LuaLS 型別補全**：自動掛載型別提示 stub，撰寫腳本時有語法提示與檢查。

## 排除檔案

在腳本資料夾（例如 `<本機資料夾>/my-script/`）放一個 `.moonclickerignore`，列在裡面的檔案在存檔、新增、改名、刪除時都不會同步到裝置。語法與 `.gitignore` 相同，例如：

```gitignore
# 原始素材
*.psd
drafts/
!drafts/keep.png
```

`.git/`、`.vscode/`、`.luarc.json`、`*.device` 與 `.moonclickerignore` 本身預設就會排除，可以用 `!` 否定。

排除只作用在從 VS Code 推上裝置的方向：裝置上的檔案照樣會同步回 VS Code。已經在裝置上的檔案，之後才加進排除規則時不會從裝置刪除，需要的話請在 App 或檔案管理員手動刪除。
